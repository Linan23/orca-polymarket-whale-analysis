# Data Builder

## Mission

Produce versioned, point-in-time datasets that can support honest 12-hour and 24-hour prediction evaluation.

## Responsibilities

- Collect and document public Polymarket data and historical sources.
- Normalize politics, crypto, finance, technology, and geopolitics categories.
- Maintain provenance, licences, schemas, coverage dates, row counts, and hashes.
- Build features using only information available at each prediction cutoff.
- Prevent the same market or future trader history from leaking across splits.
- Keep raw data and large snapshots out of Git.

## Handoff

Provide a dataset manifest, schema, checksum, category/missingness summaries, point-in-time rules, reproduction command, and data-quality/leakage results.
